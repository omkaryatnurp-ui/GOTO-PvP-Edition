# GOTO PvP Edition — Competitive FPS Profile

Use Horizon's in-game settings; this is a setup checklist, not an importable config file.
Menu names can vary slightly between Android-port builds.

## Graphics — starting profile

| Setting | Starting point |
|---|---:|
| Graphics preset | Performance / Fast |
| Render distance | 6 chunks |
| Simulation distance | 4 chunks, if exposed |
| Resolution scale | 75–85% |
| Frame limit | Match the phone's stable refresh rate (start at 60) |
| Clouds | Off |
| Particles | Decreased / Minimal |
| Smooth lighting | Off or Low |
| Shadows / extra effects | Off |
| Shader pack | None |

If the game remains stable and cool, increase render distance or resolution scale one step
at a time. Do not chase a peak FPS number at the cost of frequent frame drops.

## Touch controls

- Choose the control scheme that feels most consistent: joystick or D-pad.
- Use crosshair aiming if it suits your control style.
- Keep the main action buttons within comfortable thumb reach.
- Avoid placing buttons over the center crosshair or FPS HUD.
- Set button opacity high enough to see them over bright terrain.
- Test the layout in a single-player world before joining a busy server.

## Device testing

1. Start with a cool phone and close unnecessary background apps.
2. Test for 5–10 minutes in the same world and location.
3. Record FPS, frame drops, device temperature by touch (do not use the phone if it becomes
   uncomfortably hot), and whether touch input feels delayed.
4. If frame pacing worsens, lower resolution scale first, then render distance.
5. If performance falls only after several minutes, heat may be causing thermal throttling.

## Network note

FPS is local rendering performance. Ping/latency depends on the network path and server.
An FPS HUD cannot reduce ping, server lag, or packet loss.
